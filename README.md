# 📊 Dashboard Analítico de Vendas Globais

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um **Dashboard Analítico de Vendas Globais** utilizando o **Microsoft Power BI**, com o objetivo de transformar dados de vendas em informações visuais para facilitar a análise e interpretação dos resultados.

O dashboard foi desenvolvido como parte do **Laboratório Prático 1**, contemplando indicadores de vendas, análise por categoria, país, prioridade de entrega e subcategoria de produto.

A solução também permite que o usuário explore os dados de forma interativa por meio de filtros.

---

## 🎯 Objetivos do projeto

O dashboard foi desenvolvido para responder às seguintes perguntas:

### 1. Qual o valor total vendido?

Apresentar o **valor total das vendas realizadas**, permitindo uma visão geral do desempenho das vendas.

### 2. Quantas vendas foram realizadas por categoria de produto?

Analisar a quantidade de vendas realizadas nas diferentes categorias de produtos.

### 3. Quantas vendas foram realizadas por país considerando a prioridade de entrega?

Identificar a quantidade de pedidos realizados em cada país, permitindo também analisar a distribuição conforme a **prioridade de entrega**.

### 4. Qual foi a média de desconto nas vendas por subcategoria de produto?

Comparar a **média de desconto aplicada** entre as diferentes subcategorias de produtos.

### 5. Quais países tiveram maior média de valor de venda?

Identificar os países com maior **média de vendas**, utilizando uma representação geográfica para facilitar a interpretação dos resultados.

---

# 📈 Dashboard

O dashboard apresenta diferentes visualizações para análise dos dados:

### 💰 Total de Vendas Global

Indicador que apresenta o valor total de vendas registrado na base.

### 📊 Média de Vendas Global

Indicador utilizado para apresentar a média dos valores de venda.

### 🏷️ Total de Vendas por Categoria

Gráfico responsável por demonstrar a distribuição das vendas entre as categorias:

- Suprimentos
- Tecnologia
- Móveis

### 📉 Média de Desconto por Subcategoria

Gráfico de barras utilizado para comparar a média de desconto aplicada em diferentes subcategorias de produtos.

### 🌎 Média de Vendas por País

Mapa utilizado para demonstrar a média dos valores de venda distribuídos geograficamente.

### 🚚 Total de Vendas por País e Prioridade

Gráfico que permite analisar o total de pedidos por país considerando diferentes níveis de prioridade de entrega:

- Alta
- Baixa
- Crítica
- Média

---

# 🎛️ Filtros disponíveis

O dashboard permite ao usuário realizar análises interativas por meio dos seguintes filtros:

### 📅 Ano

Permite selecionar o período de análise.

### 👥 Segmento

Possibilita filtrar os dados pelos segmentos:

- Consumer
- Corporate
- Home Office

### 🌎 País

Permite selecionar países específicos para realizar análises direcionadas.

Esses filtros alteram dinamicamente as visualizações e os indicadores apresentados no dashboard.

# ▶️ Como visualizar o projeto

Para visualizar o dashboard localmente:

1. Faça o download do arquivo `dashboard.pbix`.
2. Instale o **Microsoft Power BI Desktop**.
3. Abra o arquivo no Power BI.
4. Utilize os filtros para explorar os dados.
5. Navegue pelas visualizações disponíveis no dashboard.
